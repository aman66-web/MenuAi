HOW TO USE: open Midjourney (midjourney.com/imagine) in Chrome and log in, open Claude in Chrome, and paste EVERYTHING below the line as one message.

When it finishes, move the downloaded files into the project folder `data/recipe-images/` and tell Claude Code "import the recipe pictures" (it runs `python3 tools/recipes/import_recipe_images.py`).
Note: Midjourney's Community Guidelines say it has no API and that automating the site can get an account blocked. The instructions below go slowly (one job at a time, stop on any warning) to keep clear of that, but it is your account: the safe alternative is to paste the prompts yourself.

You are making ONE picture for each of the 117 recipes below, using Midjourney in this browser (I am already logged in with a paid plan). RULES
1. Work in the Midjourney tab only. One recipe at a time, one job at a time. Send the next prompt only when the previous one has finished. If Midjourney says to slow down or wait, wait.
2. Paste each prompt EXACTLY as written (the only thing you may add is the style anchor in rule 5). Do not edit, shorten or add words.
3. When the four pictures are ready, choose the best one that passes EVERY test: (a) taken straight down from above, not tilted, the whole plate or bowl in view and centred with space around it; (b) shows the dish described and no other food (no lemon wedge, herbs, sauce pot or side dish the prompt does not mention); (c) no writing, letters, numbers, logos, brand names, packaging, jars, tins or bottles anywhere; (d) no hands, people, cutlery or steam; (e) natural food colours, appetising, nothing plastic, burnt or half-raw; (f) one portion on a light wooden table; (g) not almost the same picture as another recipe's.
4. Open the chosen picture, upscale it (Upscale Subtle, if offered) and download the PNG. Save it as `<recipe id>.png` (the id is the code after "id:", for example `overnight-oats.png`) in one folder called `numbite-recipe-images` in Downloads. If none of the four passes, run the same prompt again (or "Vary Subtle" on the closest one), at most 3 tries in total; if it still fails, add the id to a list called NEEDS ATTENTION and move on.

6. STOP and tell me (do not try to get past it) if Midjourney shows a CAPTCHA or human check, a login or payment page, an error about too many jobs, or any warning about my account.
7. After every 10 recipes, tell me in one line: done so far, and the NEEDS ATTENTION list. At the end tell me which ids are done, which need attention, and where the files are. Do not upload other images or add text or branding to any picture.
